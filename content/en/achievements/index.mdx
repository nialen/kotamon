## About this 40-entry list

Steam showed exactly 40 public achievements when this page was reviewed on August 25, 2026. The names and descriptions below preserve the public Steam wording. The activity groups are an editorial aid based on what each description asks the player to do.

The developer's August 21 update says several achievement issues were fixed after release. If a completed requirement does not unlock, confirm the game is current and preserve a separate good save before retesting. This reference does not assign a completion time or invent hidden requirements.

## Plan overlapping tracks

The community roadmap notes a practical conflict between the `Have` money milestones and upgrade spending. Let each balance milestone register before using the same balance for upgrade goals. Work recycling, beer, collectibles, and card checks into normal yard cycles so their public counters can progress together.

Use Steam's unlock notification and the in-game interface for open-ended wording such as all garbage, all upgrades, a full foil set, and all foil cards. The public descriptions do not state extra totals for those phrases.
