## Protect progress before repairing

Before testing the repair table, keep an existing good save untouched and create a separate manual save for the attempt. This matters most if you have already seen missing upgrades, a load crash, or any other save symptom.

Do not overwrite the only save that still contains the progress you want. Card assembly is not a recovery method for a damaged save, and the available sources do not support irreversible file editing as a repair step.

## Supported repair flow

The official GIGA patch and the current community guide support the same basic flow:

1. Collect all five fragments for the damaged card.
2. Go to the glue table in the garage.
3. Place and arrange the pieces manually on the table.
4. Complete the card only when the five pieces form the full image.
5. Check the resulting card and your collection before continuing to trade or spend.

The saved sources do not confirm an automatic assembly upgrade. They also do not establish one set of exact piece coordinates, a universal repair fee, or a safe shortcut that skips the manual puzzle.

## Manual assembly tips without invented coordinates

Work from visible edges and artwork rather than copying a fixed layout from another card. Separate obvious corners and borders first, then use matching line work and image details to place the center pieces.

If a piece does not fit, move it back and compare another edge. A different card image can require a different arrangement, so a coordinate recipe would be misleading without card-specific evidence.

## Version wording and current behavior

One line in the official GIGA announcement uses the phrase "complete map." The surrounding repair context and the current community documentation both describe a complete card, so this guide treats that wording as a likely translation issue instead of a separate map system.

The GIGA announcement predates the August 2026 release build. The five-piece garage workflow remains the supported current description in the saved research, but interface details can still change in a later patch.

## When to stop and keep the good save

Stop the attempt if loading the test save removes upgrades, resets unexpected progress, or crashes. Keep the known good save untouched and follow the [save not working guide](/en/guides/save-not-working) before trying again.

Do not repeatedly overwrite the good slot to force an assembly result. The official save fixes and later community reports are not the same evidence, so a card repair attempt should never be used to test a risky save theory.

For the larger collecting loop, return to the [gameplay guide](/en/guides/gameplay) or compare the result with the [current cards reference](/en/cards).
