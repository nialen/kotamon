## KOTAMON Save File Location

The exact local save path has not been reliably confirmed in the official sources currently available. The Steam store confirms Steam Cloud support, but it does not publish a verified Windows save folder or identify the complete local file set.

Do not substitute a guessed AppData directory, Steam userdata path or another game's save location. Until the location is positively identified from game-specific evidence, this guide does not provide a copy-and-paste save path or restore command.

## Before Troubleshooting Your Save

Stop using the affected save as soon as you notice missing upgrades, an unexpected reset or a load crash. Keep the last known good save untouched. If you can safely create a separate test slot without replacing it, do so before a diagnostic step; do not create new saves just to investigate while the only good state is at risk.

Do not overwrite the only good slot, delete saves or edit save data to test a theory. Verifying game files may check the installation, but the saved evidence does not show that it restores lost progress.

## Does KOTAMON Use Steam Cloud?

The official Steam listing confirms Steam Cloud support. That feature alone does not prove that a lost local state can be recovered or that an older version is available. Steam Support describes Cloud storage as potentially including saves, settings and other game-specific data; a sync issue and a game save bug are not automatically the same problem.

As a precaution, note any Cloud warning and the device where the last good progress was seen before launching elsewhere or choosing a replacement copy. If you cannot tell which copy is correct, pause instead of selecting an overwrite at random. Prepare the details listed below, then consult [Steam Support](https://help.steampowered.com/en/wizard/HelpWithSteamIssue/?issueid=812).

This is a preservation-first checklist, not a verified KOTAMON Cloud recovery procedure. Do not disable synchronization, delete Cloud files or reinstall as a blanket cure for missing progress.

## How to Back Up Your KOTAMON Save

An additional in-game slot and an independent file backup are different precautions. A slot is still part of the game's save system. As general data-safety advice, once the correct KOTAMON files have been positively identified, close the game and copy the complete save set to a separate dated folder before editing or replacing anything. Keep the originals and record the game version and visible progress.

Because the exact folder and file set remain unverified, do not copy a random folder merely because its timestamp changed. Do not overwrite a current save with a downloaded file whose purpose, version or account is uncertain. Ask for game-specific guidance before attempting a restoration.

## What the official August 21 update fixed

The developer's August 21, 2026 update says it addressed several save and progression problems. See the dated context in [KOTAMON Updates and Patch Notes](/en/updates). The official notes include:

- fixes for crashes connected to saving and loading;
- autosaving when a new trash pile is opened;
- fixes for several achievements;
- an intentional demo-to-release migration rule.

For demo migration, money and upgrades reset by design while the card collection remains. If that exact transition happened when moving from the demo to the full release, it is documented behavior rather than proof that the current save failed.

The developer also stated that progress already lost to those crashes could not be restored by that fix. Installing a patch and recovering an older save are different outcomes; neither a reinstall nor a successful integrity check proves recovery.

## What later community reports still describe

The community issue summary reviewed for the original guide recorded players reporting missing upgrades after the official fixes. This is historical report evidence, not confirmation that the same bug still affects every current build or that one recovery method works for everyone.

A repeated stat pattern reported by players is a symptom, not a normal cap, password, or recovery code. Do not enter or copy values into a save based on that report.

## How to Recover a KOTAMON Save

No universal KOTAMON recovery procedure has been verified by the sources used here. Recovery depends on whether a separate good slot, an independently backed-up file set or a usable Cloud copy actually exists. Preserve every candidate copy before choosing between versions, and stop if you cannot identify which one contains the correct progress.

The August 21 developer post states that its fixes could not restore progress already lost to the addressed crashes. A later patch, Steam Cloud support or a successful reinstall therefore must not be presented as a guaranteed recovery method.

## What to Do If KOTAMON Is Not Saving

1. Leave the last good save untouched.
2. Use a separate manual slot only if it can be created without overwriting the good state. Otherwise stop and seek support.
3. Confirm the game is updated through Steam before reproducing an issue already named in the August 21 notes.
4. Decide whether the change matches the documented demo migration or affects a full-release save.
5. On the test save only, note the upgrade values before and after one normal save and load cycle.
6. Note whether opening a new trash pile produces the autosave behavior described by the official update.
7. Stop if another load removes progress or crashes. Do not repeat the test on the good save.

This sequence separates a known migration rule, an officially addressed bug, and a current player-reported symptom without assuming they have the same cause.

## Information to include when escalating

A useful report should include:

- whether the save began in the demo or the full release;
- the date the game was last updated;
- the values or upgrades visible before and after loading;
- the last normal action before the problem appeared;
- whether a new trash pile had been opened;
- whether the card collection remained;
- whether the game crashed or loaded with changed progress.
- whether Steam displayed a Cloud warning and which device last showed the correct progress.

Share a reproducible description through the game's current community or developer support channel. Keep the preserved save untouched while waiting for official guidance, and do not claim a community workaround is an official fix.

## Continue only from a verified state

After one successful test load, compare the important progress again before continuing. If the values are still wrong, stop and retain both the untouched good save and the separate test save.

For normal progression after the save is stable, use the [gameplay guide](/en/guides/gameplay). If the issue appeared while assembling a fragmented card, use the [card repair guide](/en/guides/card-repair) without overwriting the known good slot.

### Where is the KOTAMON save file located?

The exact local save location remains unverified in the official sources currently available, so this guide does not present a Windows path as fact.

### Does KOTAMON support Steam Cloud?

Yes. The official Steam listing shows Steam Cloud support. That does not guarantee that an older or correct copy is recoverable.

### How do I back up my KOTAMON save?

First identify the complete game-specific file set from reliable evidence, close the game, and copy the files to a separate dated folder. Do not use a guessed path or overwrite the originals.

### Why is KOTAMON not saving?

The available evidence does not establish one cause for every symptom. Compare the documented demo migration, the August 21 fixes, any current crash and any Steam Cloud warning before treating them as the same problem.

### Can I recover a lost KOTAMON save?

Not necessarily. Cloud support, official bug fixes and the existence of a recoverable good copy are separate questions. Preserve what remains and include the symptoms in a support report.
